A vibrant, responsive educational landing page for an online learning and academy platform ("eSchool"). Designed to highlight online courses, stats, student enrollment, and testimonials using Bootstrap 5 and modern CSS.

Experience the live website on GitHub Pages:

## ✨ Features

- **Hero Header Section**: Welcoming tagline, CTA button ("Ready to Learn? Get Started"), and modern educational illustration.
- **Key Metrics & Highlights**: Fast stats breakdown including 1500+ topics, 1800+ students, 9k+ test tokens, and 2000+ student enrollments.
- **Online Courses Catalog**: Interactive course cards with instructor details, start schedules, seat counters, and enrollment buttons.
- **Student Testimonials**: Community feedback review section with student quote and avatar.
- **Multi-Column Footer**: Comprehensive navigation links covering Courses, Terms, Useful Links, and copyright info.
- **Fully Responsive**: Optimized for phones, tablets, and wide desktop screens.

---

## 🛠️ Built With

- **HTML5**: Semantic layouts and accessible structure
- **CSS3**: Custom shadows, transitions, borders, and color schemes
- **Bootstrap 5 (5.0.2)**: Grid system, flex utilities, and responsive breakpoints
- **Bootstrap Icons (1.5.0)**: Clean icon integration
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins)
- **GitHub Pages**: Static site hosting

## 🚀 Getting Started

To run the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tawsifx/e-school.git
   ```

2. **Navigate into the folder:**
   ```bash
   cd e-school
   ```

3. **Open `index.html`** in your browser, or run a local static server:
   ```bash
   python3 -m http.server 3000
   ```
